# Boss Rush

A Cuphead-style platformer where every boss is made from a photo.

Drop photos into `~/skyphot`. Each one gets its background removed and becomes a boss with a name, title and taunt, generated by AI when you've added an API key. Then you fight them in the browser.

## Play

**Online:** https://rhysflores.github.io/skyler/ (plays with the bosses in this repo)

**Locally, with your own photos:**

```sh
git clone https://github.com/RhysFlores/skyler.git
cd skyler
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
./start.sh
```

`start.sh` turns new photos in `~/skyphot` into bosses (checking every few seconds) and opens the game at http://localhost:8000.

**Optional AI names:** copy `.env.example` to `.env` and add an Anthropic API key. Without a key, bosses get random names.

## Controls

| Action | Keys |
|---|---|
| Move | A / D or ← / → |
| Jump | W, Space or ↑ (tap for a short hop) |
| Shoot | Hold J, X or the mouse button |
| Dash | Shift |
| Drop through platform | S or ↓ |

## Files

- `web/index.html`: the whole game (one file, plain canvas, no build step)
- `web/bosses/`: boss cutouts plus `index.json` (names, titles, taunts)
- `pipeline.py`: photo → background removal (rembg) → AI naming (Claude) → boss
- `scan.py`: scans `~/skyphot` (use `--watch` to keep checking)
